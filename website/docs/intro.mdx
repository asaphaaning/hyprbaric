## What it includes

- Workspaces, active window title, optional global menu, tray, notifications, audio, power, and network widgets
- Screenshots, color picking, recording, night light, and caffeine controls
- TOML configuration with a settings GUI for appearance, modules, workspaces, night light, and shortcuts

## Development

```bash
flutter pub get
flutter run -d linux
```

For native changes:

```bash
cargo test --manifest-path native/hyprbaric/Cargo.toml
cargo test --manifest-path native/hub/Cargo.toml
flutter analyze lib test
flutter test
```

## Packaging

Packaging metadata lives in `packaging/`. Current targets are AppImage, DEB, RPM, and Pacman.
